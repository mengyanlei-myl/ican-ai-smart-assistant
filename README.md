# 🚁 低空设备智能选型系统

## 项目说明
基于真实设备数据库的无人机系统智能选型工具

## 功能页面
- `task_input.html` - 任务输入
- `requirement_confirmation.html` - 需求确认
- `candidate_devices.html` - 候选设备
- `initial_solution.html` - 初步方案

## 快速开始
双击 `task_input.html` 用浏览器打开即可
